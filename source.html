ledger-bot v1.0.0 $0 · Free

An OwO-style economy and animal-collecting Discord bot. Players hunt 26 animals, keep a zoo and battle wild teams. There's also coinflip, slots and blackjack, plus gems, lootboxes, daily streaks and leaderboards. Built with discord.py 2 and SQLite, and every command works with a prefix or as a slash command.

Quick start

unzip ledger-economy-bot-python.zip && cd ledger-bot
pip install -r requirements.txt
cp .env.example .env   # add DISCORD_TOKEN
python -m ledger
